OAXO — atualização visual v1 (base Equilíbrio v33.3)

Esta versão atualiza a identidade visual para OAXO: nome, slogan, paleta preta/prateada, manifesto PWA, ícones e cache do service worker.

PRESERVAÇÃO: mantém app.js, as integrações Firebase existentes, as regras Firestore e os módulos da versão-base. Não cria projeto Firebase novo e não apaga dados do banco.

ANTES DE PUBLICAR:
1. Guarde uma cópia da versão atualmente publicada e exporte os dados locais pelo recurso de backup do app, se houver registros apenas neste navegador.
2. Extraia os arquivos deste ZIP e envie-os para a raiz do repositório GitHub Pages, substituindo os arquivos correspondentes.
3. NÃO substitua firestore.rules no Firebase Console sem revisar/publicar conscientemente; o arquivo incluído é mantido da versão-base.
4. No Firebase Console > Authentication > Settings > Authorized domains, adicione oaxo.com.br quando for usar o novo domínio. Confira também a configuração OAuth do Google se o fluxo de login exigir.
5. Configure o domínio no GitHub Pages apenas depois que o DNS estiver pronto.
6. Teste login Google, dados, sincronização, alimentação, treinos, finanças e instalação PWA.

IMPORTANTE SOBRE DADOS LOCAIS: navegadores tratam o domínio antigo e oaxo.com.br como origens diferentes. Dados sincronizados no mesmo projeto Firebase devem continuar associados à mesma conta; dados guardados somente no armazenamento local do navegador não migram automaticamente entre domínios. Mantenha o endereço antigo disponível até conferir tudo.

Esta atualização não foi publicada no GitHub nem testada contra o Firebase real.
