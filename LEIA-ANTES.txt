1. Faça backup do repositório atual antes de substituir arquivos.
2. Extraia este ZIP e envie os arquivos para a raiz do repositório GitHub Pages, mantendo a estrutura.
3. Publique por commit e aguarde o GitHub Pages concluir.
4. O service worker usa uma nova chave de cache para reconhecer esta versão.
5. Teste login, feed, alternância Para você/Seguindo, Publicar, perfil, selos, Finanças, Alimentação, Treinos, tema claro/escuro e sincronização em PC e iPhone.
6. Não altere as regras do Firestore nem ative Firebase Storage pago para esta atualização visual.

Mudança de escopo: esta versão redesenha apenas a tela Início. Os filtros de feed são locais e usam dados já carregados; alternar os filtros não faz novas leituras ao Firestore. “Para você” significa o conjunto de publicações públicas/permitidas que já foi carregado, não um algoritmo de recomendação.

Validações automáticas realizadas: sintaxe JavaScript, JSON do manifest e integridade do ZIP. Não foi feito teste real no Firebase ou em dispositivos.
