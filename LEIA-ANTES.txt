OAXO - atualizacao visual v2 (base Equilibrio v33.3)

Esta versao aplica identidade visual mais evidente: preto profundo, grafite, prata, gradientes metalicos discretos, cartoes com profundidade, botoes e abas redesenhados, simbolo OAXO e novos icones PWA.

PRESERVACAO: app.js e configuracoes Firebase existentes sao mantidos; nao cria projeto Firebase novo nem apaga dados do banco.

ANTES DE PUBLICAR:
1. Guarde uma copia da versao atualmente publicada e exporte dados locais pelo recurso de backup do app.
2. Extraia o ZIP e envie os arquivos para a raiz do repositorio GitHub Pages, substituindo os correspondentes.
3. Nao publique/substitua firestore.rules no Firebase Console sem revisar conscientemente.
4. Ao migrar para oaxo.com.br, adicione o dominio em Firebase Authentication > Settings > Authorized domains.
5. Depois de publicar, faca recarga forcada no navegador (Ctrl+F5). No iPhone, feche e reabra o app instalado; se necessario, remova e reinstale o atalho para atualizar o icone.
6. Teste login Google, dados, sincronizacao, alimentacao, treinos, financas e instalacao PWA.

IMPORTANTE: dominio antigo e novo sao origens diferentes. Dados sincronizados no mesmo projeto Firebase devem continuar associados a mesma conta; dados somente locais nao migram automaticamente. Mantenha o endereco antigo ate conferir tudo.

Esta atualizacao nao foi publicada nem testada contra o Firebase real.
