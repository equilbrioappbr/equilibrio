EQUILÍBRIO — PACOTE DE CORREÇÃO

IMPORTANTE
Este ZIP NÃO contém o projeto completo nem substitui o index.html. Como não foi possível recuperar a versão atual do repositório, ele contém um script que aplica a correção ao index.html existente, preservando o restante do código.

O que a correção faz
- Mantém uma tela “Carregando Equilíbrio…” enquanto o Firebase restaura a sessão e os dados da conta.
- Evita mostrar o formulário de login por um instante quando o usuário já está autenticado.
- Faz a tela de login voltar a aparecer normalmente quando não há sessão ou ocorre erro de sincronização.

Como usar (Windows)
1. Baixe o index.html atual do repositório: https://github.com/equilbrioappbr/equilibrio/blob/main/index.html
   No GitHub, abra o arquivo e use o botão de download (ou Raw > salvar como).
2. Faça uma cópia de segurança do index.html baixado.
3. Coloque corrigir_equilibrio.py na mesma pasta do index.html.
4. Abra o Terminal/Prompt nessa pasta e execute:
   python corrigir_equilibrio.py index.html
5. O script cria index_corrigido.html; ele não sobrescreve o arquivo original.
6. Revise o resultado antes de substituir o index.html no GitHub. Faça commit apenas depois de conferir.

Se o script disser que não encontrou um trecho, NÃO force a alteração: significa que o código do repositório está diferente do esperado e precisa ser ajustado manualmente.
